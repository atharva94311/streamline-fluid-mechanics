# Course PDFs (local only)

The PDFs are not committed because they are copyrighted course material. To make the source chips open the exact
page when you run the platform locally, copy your files here with these names:

| File name here | Your original file |
|---|---|
| `FM_Lec9.pdf` … `FM_Lec13.pdf` | `FM_Lec9.pdf` … `FM_Lec13.pdf` |
| `Fox_McDonald_excerpt.pdf` | `Fox and McDonalds (1).pdf` |
| `Wilkes_Ch9_Turbulent_Flow.pdf` | `Wilke's Fluid Mechanics for Chemical Engineers-499-560.pdf` |

Without them the platform still works; chips just show the slide/page reference.
